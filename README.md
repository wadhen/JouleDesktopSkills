# JouleDesktopSkills

A collection of custom skills for Joule Work Desktop.

## Structure

    skills/
    └── <skill-slug>/
        └── SKILL.md

## Skills

| Skill | Description |
|-------|-------------|
| [weekly-published-roles-digest](skills/weekly-published-roles-digest/SKILL.md) | Reads last week's published role emails, evaluates them against your profile and seniority level, and presents matches first. |
